# 🌿 Visión del Producto: Komorebi

## Declaración Formal de Visión (Product Vision Statement)

- **Para:** Personas que desean construir y mantener hábitos diarios y rutinas personales (deporte, bienestar, estudio o descanso).
- **Que se enfrentan a:** La fricción de arrancar cada día, la frialdad de las listas de tareas tradicionales y la ansiedad generada por las aplicaciones punitivas que reinician el progreso a cero ante un fallo involuntario.
- **Komorebi es:** Una aplicación web de microhábitos fundamentada en la gamificación amable (*cozy gaming*) y el refuerzo visual positivo.
- **Que proporciona:** Un mecanismo de marcado en un solo clic, con confirmación visual inmediata (< 500 ms), que hace florecer un hábitat virtual vivo (al estilo *Tamagotchi* o jardín zen).
- **A diferencia de:** Herramientas tradicionales como Habitica (que quitan vida), Forest (que mata árboles) o las frías hojas de cálculo.
- **Nuestro producto:** Protege la motivación y la salud emocional del usuario mediante un **diseño no punitivo**, donde un día de pausa activa el **Modo Reposo / Día Nublado**, preservando intacto el 100 % de la energía y el esfuerzo acumulado, sin culpa ni reseteos.

## Delimitación: Qué ES y Qué NO ES

| ✅ Qué ES Komorebi | ❌ Qué NO ES Komorebi |
| :--- | :--- |
| Un catalizador de microhábitos diarios en un solo clic. | Un gestor empresarial complejo (tipo Jira o Trello). |
| Un refugio visual de calma y refuerzo positivo (*cozy*). | Un videojuego absorbente que robe tiempo real. |
| Un compañero virtual vivo (espíritu *Tamagotchi*). | Una aplicación punitiva que cobre por recuperar rachas. |
| Un sistema web accesible y responsivo (DAM). | Una red social competitiva de comparación pública. |
